# Working in this roadmap

For requests to learn, practise, review understanding, plan study time or resume progress, use the `roadmap-tutor` skill. If it is not installed, read [the versioned skill](resources/tutor/roadmap-tutor/SKILL.md). The learner-facing entry is [agent.md](agent.md). Tutor sessions use the current semester/module and private evidence, not historical audit results as learner progress.

For curriculum, code, documentation, installation or review work, act as an implementation collaborator; do not turn maintenance into a quiz. Read applicable guidance in [CONTRIBUTING.md](CONTRIBUTING.md) and [tools/README.md](tools/README.md). Preserve existing changes, explicit anchors, canonical manifest IDs/prerequisites, free lecture routes and optional paid books. Regenerate manifest-derived sections with the existing checker when their source changes.

Keep learner records in ignored `study-private/`. Do not publish private progress, alter provider credentials/configuration as a side effect, or claim that supplied reference solutions demonstrate learner mastery. Run checks relevant to changes and report what actually executed.
